Réalisation d’un site web

Conception et codage d'un site web interactif — projet mené seul (2021)

Description

Ce projet, réalisé en 2021, consistait à créer un site complet entièrement codé à la main en HTML et CSS. Il devait respecter plusieurs contraintes : présence d’un sommaire, d’un fil d’Ariane, d’un en-tête et d’images.

Ci-dessous, un exemple du rendu du sommaire. Ce projet m’a permis de comprendre et de maîtriser les bases du HTML/CSS, ainsi que les enjeux techniques et pratiques de la conception d’un site internet.

Compétences travaillées

  • Développement d’outils informatiques à usage interne d'une équipe.
  • Développer une application à partir d’un cahier des charges, pour le Web ou mobile.
